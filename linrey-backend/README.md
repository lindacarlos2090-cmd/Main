# LynRey Afric Car Rentals – Website Prototype

Open `index.html` in a browser to preview the website.

## Included
- Responsive homepage and fleet
- Mazda CX-5, Toyota Prado TX, Toyota Prado TXL
- Automatic date-overlap checking in the browser demo
- Rental cost calculation
- Demo M-Pesa checkout flow
- Rental requirements and contact details

## Important: Live M-Pesa
The current M-Pesa screen is a **prototype**. A production payment system must use Safaricom's approved Daraja/M-Pesa API through secure server-side code. Do not place API secrets in browser JavaScript.

## To publish with WordPress
This design can be recreated as a custom WordPress theme/page design, with a proper booking plugin/backend and a production M-Pesa gateway.
